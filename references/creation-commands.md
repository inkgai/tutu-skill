# 图图创作指令格式（小白版）

**不用记字段，也不用先学提示词。** 直接用平常说话描述就可以，图图会把你的话整理成画面方案，先告诉你准备怎么画，再开始生成。

## 0. 最简单的说法

只要说清楚「想做什么、画什么、准备发到哪里」，其他都可以不填：

```text
帮我做一张【用途】，画面是【主体 + 场景 + 动作】，风格要【风格】，比例用【比例】。
```

可以直接复制这些例子：

```text
帮我做一张小红书封面：一位年轻营养师在明亮厨房里举着沙拉，清透生活方式摄影，3:4，不要生成文字。

帮我做一个 4 格漫画：孩子第一次学会骑自行车，温暖治愈风，先给我看分镜。

给这篇文章配 4 张公众号插图，主题是睡眠习惯，温暖扁平插画，比例 16:9。文章正文如下：……

画一个从“提出问题”到“发布文章”的流程图，四个节点，简洁蓝绿色，输出到灵感画板。
```

### 不确定时怎么写

- 不知道比例：写“你帮我选适合小红书/公众号的比例”。
- 不知道风格：写“清晰、舒服、适合科普”，图图会先给推荐。
- 不知道空间：写“先列出我的空间让我选”。
- 不想要图片文字：写“不要生成文字，后期排版”。
- 想保持人物一致：写“每张图保持同一个角色的脸型、发型和服装”。

图图只会在缺少**创作类型**或**核心主体**时追问；比例、风格、构图等可选项会先用合理默认值，并在扣费前展示整理结果。

### 默认值速查

| 类型 | 不填写时怎么处理 |
|---|---|
| 单图 | 1 张、方图 `1:1`、不在画面里生成文字 |
| 漫画 | 4 格、先给你看分镜；治愈故事用字幕条，趣味对话用气泡 |
| 文章配图 | 4 张，按段落分布；比例按用途推荐 |
| 画板图解 | 输出可继续编辑的图解文件 |
| 海报策划 | 1 页、按用途推荐比例 |
| 模板设计 | 分类、比例、参考图都可以留空，后续在网页里补充 |

## 进阶模板

下面模板是给想精确控制画面的人使用的，**不用全部填写**。

## 1. 单张图片 / 海报 / 封面

```text
[图图·单图]
用途：[必填] 小红书封面 / 公众号头图 / 屏幕背景 / 商品图
主体：[必填]
场景与动作：[可选]
构图：人物放哪里、近景/半身/全身、哪里留白[可选]
风格：写实 / 水彩 / 国风 / 漫画 / 信息图……[可选]
色彩与光线：[可选]
比例：3:4 竖图 / 4:3 横图 / 1:1 方图 / 16:9 横屏 / 9:16 长屏[可选]
画面文字：不生成；或填写必须逐字出现的短文案[可选]
参考图：可不填，本地图片或图图地址，最多 3 张
不要出现：[可选]
数量：1
```

示例：

```text
[图图·单图]
用途：小红书封面
主体：一位戴圆框眼镜的年轻营养师
场景与动作：明亮厨房里举起一盘彩色沙拉，面向镜头微笑
构图：半身，人物在右侧，左侧留标题区
风格：清透生活方式摄影，柔和自然光
色彩与光线：奶油白、浅绿色、低饱和
比例：3:4
图中文字：不生成文字，后期排版
不要出现：水印、乱码、额外人物
```

## 2. AI 漫画

```text
[图图·漫画]
空间（风格空间）：不知道可写“先列出我的空间让我选”[可选]
故事：[必填] 起因、经过、转折、结尾
格数：1-8，默认 4 格[可选]
比例：1:1 方图 / 3:4 竖图 / 4:3 横图 / 16:9 横屏 / 9:16 长屏[可选]
风格：治愈 / 趣味 / 职场 / 对比 / 国风 / 手绘……[可选]
画面形式：字幕条 / 对话气泡 / 纯画面[可选]
步骤：先给我看分镜；或直接出图[可选]
人物保持：外观、服装、发型跨格一致[可选]
必须出现的文字：[可选]
```

默认先生成分镜供你确认。只有写了“直接出图”才跳过分镜。

## 3. 文章配图

```text
[图图·配图]
文章：[必填] 粘贴正文（建议 300 字以上）
用途：公众号 / 小红书 / 知识图文 / 文章插图[可选]
张数：1-10，默认 4 张[可选]
比例：1:1 方图 / 3:4 竖图 / 4:3 横图 / 16:9 横屏 / 9:16 长屏[可选]
风格：温暖 / 知识图 / 小红书 / 职场 / 文艺 / 可爱……[可选]
画面文字：纯画面；或图文融合（只放短句）[可选]
角色：角色模板 ID 或外观约束[可选]
参考图：可不填，最多 3 张
```

文章配图会按文章段落分布画面。如果生成中途失败，保留作品编号并继续查询或重试，不要连续创建多个扣费任务。

## 4. 灵感画板 / 结构化图解

```text
[图图·画板]
类型：流程图 / 架构图 / 知识图 / 时间线 / 对比图
主题：
节点：按顺序列出节点名称
关系：说明箭头方向、分支条件或层级
风格：简洁 / 手绘 / 黑白 / 彩色
输出：tutu.json，可在图图画板继续编辑
```

这类请求调用 `diagram.py`，会输出可导入图图画板的 `.tutu.json`。

## 5. 灵感画报策划（网页登录）

```text
[图图·海报策划]
主题：
受众：
页数：1-8
每页重点：第 1 页……；第 2 页……
统一风格：
比例：2.35:1 / 16:9 / 3:2 / 4:3 / 1:1 / 3:4 / 2:3 / 9:16
文字模式：纯画面 / 图文融合
参考图：最多 3 张
```

当前走已登录图图网页；skill 先生成规划 payload，再进入网页提交。

## 6. 画板模板设计

```text
[图图·画板模板]
名称：
用途：例如小红书知识卡、公众号封面、活动海报
版式规则：标题区、主视觉区、信息区、行动区的位置和层级
统一视觉：颜色、字体气质、边距、留白、插画风格
参考图：
推荐比例：3:4 / 4:3 / 16:9 / 9:16 / 1:1
```

## 7. 角色模板设计

```text
[图图·角色模板]
名称：
创作分类 ID：
身份与性格：
外观规则：年龄、脸型、发型、服装、配色、标志性配件
不可改变：跨作品必须保持的特征
适用场景：漫画 / 配图 / 立绘
参考图：
推荐比例：1:1 / 3:4 / 4:3
```

## 交互约定

1. skill 先回一段“已整理需求”，列出类型、比例、风格、文字处理和是否使用参考图。
2. 只有缺少会改变结果或计费的字段才追问；可选项使用默认值并说明。
3. 漫画先给分镜；用户说“确认/开始生图”后再渲染。
4. 生成中始终报告 `N/M`，不要只说“完成”；结束后列出全部图片地址。
5. 用户说“重试”时优先复用原作品或 workId，避免重复扣费。
