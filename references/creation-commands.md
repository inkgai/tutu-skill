# 图图创作指令格式

用户可以直接复制下面的模板填写。没有把握的字段可以留空，skill 会根据用途补默认值；
类型、主体、用途和核心文字缺失时会先追问，不会直接扣费。

## 1. 单张图片 / 海报 / 封面

```text
[图图·单图]
用途：小红书封面 / 公众号头图 / 屏幕背景 / 商品图
主体：
场景与动作：
构图：主体位置、景别、留白位置
风格：写实 / 水彩 / 国风 / 漫画 / 信息图……
色彩与光线：
比例：3:4 / 4:3 / 1:1 / 2:3 / 3:2 / 16:9 / 9:16
图中文字：无；或填写必须逐字出现的短文案
参考图：本地图片路径或图图 OSS 地址（最多 3 张）
不要出现：
数量：1
```

示例：

```text
[图图·单图]
用途：小红书封面
主体：一位戴圆框眼镜的年轻营养师
场景与动作：明亮厨房里举起一盘彩色沙拉，面向镜头微笑
构图：半身，人物在右侧，左侧留标题区
风格：清透生活方式摄影，柔和自然光
色彩与光线：奶油白、浅绿色、低饱和
比例：3:4
图中文字：不生成文字，后期排版
不要出现：水印、乱码、额外人物
```

## 2. AI 漫画

```text
[图图·漫画]
空间：空间名称；不知道可写“先列出空间让我选”
故事：起因、经过、转折、结尾
格数：1-8
比例：1:1 / 3:4 / 4:3 / 2:3 / 3:2 / 16:9 / 9:16
风格：治愈 / 趣味 / 职场 / 对比 / 国风 / 手绘……
形式：字幕条 / 气泡对话 / 纯画面
流程：先看分镜；或直接出图
角色约束：外观、服装、发型、跨格保持一致
必须出现的文字：
```

默认先生成分镜供确认。只有写了“直接出图”才跳过分镜 review。

## 3. 文章配图

```text
[图图·配图]
文章：粘贴正文（建议 300 字以上）
用途：公众号 / 小红书 / 知识图文 / 文章插图
张数：1-10
比例：1:1 / 2:3 / 3:4 / 4:3 / 3:2 / 16:9 / 9:16
风格：温暖 / 知识图 / 小红书 / 职场 / 文艺 / 可爱……
文字模式：纯画面；或图文融合（只放短句）
角色：角色模板 ID 或外观约束
参考图：最多 3 张
```

文章配图会按文章段落分布画面。当前生产后端已放开 `16:9` 和 `9:16`；若旧服务返回比例校验错误，
先检查部署版本并重试，不要重复创建多个扣费任务。

## 4. 灵感画板 / 结构化图解

```text
[图图·画板]
类型：流程图 / 架构图 / 知识图 / 时间线 / 对比图
主题：
节点：按顺序列出节点名称
关系：说明箭头方向、分支条件或层级
风格：简洁 / 手绘 / 黑白 / 彩色
输出：tutu.json，可在图图画板继续编辑
```

这类请求调用 `diagram.py`，会输出可导入图图画板的 `.tutu.json`。

```text
[图图·海报策划]
主题：
受众：
页数：1-8
每页重点：第 1 页……；第 2 页……
统一风格：
比例：2.35:1 / 16:9 / 3:2 / 4:3 / 1:1 / 3:4 / 2:3 / 9:16
文字模式：纯画面 / 图文融合
参考图：最多 3 张
```

当前走已登录图图网页；skill 先生成规划 payload，再进入网页提交。

```text

统一视觉：颜色、字体气质、边距、留白、插画风格
参考图：
推荐比例：3:4 / 4:3 / 16:9 / 9:16 / 1:1
```

## 交互约定

1. skill 先回一段“已整理需求”，列出类型、比例、风格、文字处理和是否使用参考图。
2. 只有缺少会改变结果或计费的字段才追问；可选项使用默认值并说明。
3. 漫画先给分镜；用户说“确认/开始生图”后再渲染。
4. 生成中始终报告 `N/M`，不要只说“完成”；结束后列出全部图片地址。
5. 用户说“重试”时优先复用原作品或 workId，避免重复扣费。
